# v1.0 - UX da tela Criacao de Robo

## Intencao
Preservar a visao de produto para a tela de criacao do robo, agora consolidada como uma experiencia de layout triplo, inspirada na experiencia do VS Code com Copilot, sem perder foco tecnico do IA-GO.

## Referencia de experiencia
1. Painel esquerdo com lista de bots e contexto de selecao.
2. Painel central com conversa/comando em linguagem natural.
3. Painel direito com preview tecnico e edicao do codigo Python.
4. Feedback incremental durante geracao, semelhante a assistente de codigo.

## Componentes da tela
1. Coluna 1 - Lista de bots
- Lista de todos os bots.
- Busca e filtro por status.
- Selecao do bot ativo para continuar conversa ou revisar versoes.

2. Coluna 2 - Chat com IA
- Composer principal para descrever automacao em linguagem natural.
- Historico da conversa por bot/versao.
- Perguntas pendentes e refinamento incremental.

3. Coluna 3 - Saida tecnica
- Codigo Python gerado.
- Mini terminal/visualizador para inspecao e ajuste manual.
- Preview do contrato e mensagens de validacao.

4. Acoes rapidas
- Teste imediato (ad_hoc_test).
- Salvar como draft.
- Solicitar aprovacao.
- Publicar versao.

## Mini fluxograma visual (conceito)
1. Selecionar bot na lista ->
2. Conversar com a IA ->
3. Gerar/refinar codigo e contrato ->
4. Revisar na saida tecnica ->
5. ad_hoc_test ->
6. Ajustes ->
7. Aprovacao ->
8. Publicacao ->
9. Execucao em fila.

## Fluxograma de estados (versao curta)
1. Draft -> Tested -> Approved -> Published.
2. Em falha no teste, retorna para Draft com feedback.
3. Runtime de producao executa sem IA no loop.

## Diretrizes de UX
1. Linguagem simples para usuario nao tecnico.
2. Modo avancado opcional para time tecnico.
3. Sempre mostrar o que falta para prosseguir (perguntas pendentes).
4. Nao expor segredos em tela ou logs.
5. Nao perder contexto do chat ao trocar entre bots.
6. A coluna de saida deve permitir leitura e pequenos ajustes sem parecer uma IDE completa.

## Requisitos funcionais futuros
1. Timeline de geracao/refino por versao.
2. Diff entre versoes de codigo e contrato.
3. Simulacao de execucao com dados de exemplo.
4. Painel de evidencias (screenshot/html/logs) no mesmo fluxo.

## Requisitos nao funcionais futuros
1. Resposta visual em tempo quase real na geracao.
2. Acessibilidade basica (teclado, contraste, labels).
3. Responsividade para desktop e laptop.

## Fora de escopo da v0.1
1. Clone fiel visual do VS Code.
2. Editor completo com todas as features de IDE.
3. Sistema de colaboracao multiusuario em tempo real.
