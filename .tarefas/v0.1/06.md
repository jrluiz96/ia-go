# v0.1 - Plano de testes e qualidade

## Objetivo
Garantir que a v0.1 seja publica com previsibilidade operacional e risco controlado.

## Piramide de testes
1. Unitarios
- Validacao de contrato.
- Mapeamento de erro.
- Regras de transicao de estado.

2. Integracao
- API Go <-> PostgreSQL.
- API Go <-> Queue.
- Scheduler/dispatcher/worker no fluxo completo.

3. E2E
- Criar bot por NL.
- Executar ad_hoc_test.
- Aprovar e publicar.
- Rodar agendado e validar resultado.

## Casos criticos obrigatorios
1. Credencial ausente/invalida.
2. Timeout de etapa de login.
3. Falha transitoria com retry.
4. Falha fatal sem retry.
5. Duplicate run_id bloqueado.
6. Worker sem heartbeat.

## Criterios de aceite da v0.1
1. 100% dos endpoints principais com teste de integracao.
2. Contrato v1 validado em entrada e saida.
3. Nenhum segredo exposto em logs.
4. Publicacao bloqueada sem validacoes minimas.
5. Rollback funcional para versao anterior aprovada.

## Gate de release
1. Testes unitarios passando.
2. Testes de integracao passando.
3. Checklist de seguranca aprovado.
4. Smoke test de scheduler/fila/workers aprovado.
