# v0.1 - Roadmap de entregas

## Diretriz de escopo
v0.1 foca em web automation com Playwright e runtime deterministico minimo. Itens avancados ficam para v0.2+.

## Fase 1 - Fundacao (Semana 1)
1. Estrutura inicial do backend Go.
2. Modelagem inicial do banco.
3. Contrato v1 fechado e validadores.
4. Decisoes bloqueantes fechadas (fila, secret store, artifact store, LLM provider).

## Fase 2 - Criacao e teste (Semana 2)
1. Endpoint de geracao de bot por NL.
2. Endpoint de ad_hoc_test.
3. Persistencia de bot_version.
4. Exibicao de logs e artifacts do teste.

## Fase 3 - Publicacao e runtime (Semana 3)
1. Ciclo de vida minimo (draft/approved/published).
2. Scheduler + dispatcher.
3. Fila + worker Python unico.
4. Persistencia de bot_runs.

## Fase 4 - Estabilidade (Semana 4)
1. Retry policy e idempotencia.
2. Heartbeat e deteccao de travamento.
3. Hardening minimo de seguranca para secrets e logs.
4. Smoke test de release e runbook operacional basico.

## Marco de release v0.1
1. Criar bot, testar, aprovar e publicar.
2. Executar por cron com fila.
3. Auditar run completa com resultado e erro padronizado.

## Itens adiados para v0.2+
1. Desktop RPA Windows (GUI local).
2. Ciclo de vida completo com 7 estados.
3. Dashboard e alertas avancados.
4. Multi-tenant completo.
