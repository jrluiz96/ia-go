# v0.1 - Passo 02: Backend Go

## Objetivo
Inicializar backend Go para CRUD de bots, execucao ad_hoc_test e pipeline de runtime minimo.

## Pre-condicoes
1. Go 1.22+ instalado na maquina.
2. PostgreSQL ativo (Passo 01 concluido).
3. Variaveis de conexao configuradas.

## Escopo backend v0.1
1. API REST basica.
2. Validacao do contrato v1.
3. Persistencia de bots/versoes/runs.
4. Endpoint ad_hoc_test.
5. Scheduler + dispatcher minimo.

## Estrutura sugerida
1. cmd/api
2. internal/http
3. internal/domain
4. internal/repository/postgres
5. internal/service
6. internal/scheduler
7. migrations

## Tarefas
1. Inicializar modulo go e estrutura de pastas.
2. Implementar conexao Postgres com pool.
3. Criar endpoints:
- POST /bots
- POST /bots/{id}/versions
- POST /bots/{id}/ad-hoc-test
- POST /bots/{id}/publish
- GET /runs

4. Implementar validacao do envelope v1.
5. Implementar persistencia de run com status padrao.
6. Implementar scheduler simples para publicar jobs em fila.

## Criterios de aceite
1. API sobe localmente.
2. Endpoints principais respondem 2xx/4xx corretos.
3. Erros mapeados para retryable_error/fatal_error.
4. run_id e trace_id registrados em logs.

## Definicoes obrigatorias
1. Fila escolhida (Redis Streams ou RabbitMQ).
2. Secret provider v0.1.
3. Storage de artifacts v0.1.
