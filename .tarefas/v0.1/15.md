# v0.1 - Passo 04: Integracao e go-live controlado

## Objetivo
Validar ponta a ponta backend + worker + frontend antes do piloto.

## Fluxo de validacao
1. Criar bot por NL no frontend.
2. Gerar codigo Python com template oficial.
3. Rodar ad_hoc_test e validar output.
4. Aprovar e publicar versao.
5. Rodar execucao agendada.
6. Auditar run no historico.

## Checklist tecnico
1. Postgres healthy.
2. API Go ativa.
3. Worker Python ativo.
4. Fila operando sem backlog anormal.
5. Logs com run_id/trace_id.

## Checklist funcional
1. Tela de criacao funciona.
2. Perguntas pendentes aparecem quando faltar contexto.
3. Teste imediato retorna artifacts.
4. Publicacao bloqueia versao invalida.
5. Consulta de execucoes retorna status correto.

## Go-live v0.1
1. Iniciar com 1 ou 2 bots piloto.
2. Janela de observacao inicial de 7 dias.
3. Revisao diaria de incidentes e falhas.
4. Ajustes de contrato e UX antes de ampliar escopo.
