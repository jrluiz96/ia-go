# v0.1 - Plano de processamento por IA

## Objetivo
Definir o fluxo operacional para a IA implementar o sistema em 3 trilhas:
1. Infra: PostgreSQL em container.
2. Backend: API Go + scheduler/dispatcher.
3. Frontend: reconstruir produto IA-GO removendo legado Bash.

## Ordem obrigatoria de execucao
1. Passo 01: Infra de dados.
2. Passo 02: Backend Go.
3. Passo 03: Frontend IA-GO.
4. Passo 04: Integracao ponta a ponta.

## Regras gerais para execucao pela IA
1. Sempre validar pre-condicoes antes de criar/alterar arquivos.
2. Nunca sobrescrever segredos em texto puro.
3. Priorizar mudancas pequenas e validaveis.
4. Registrar no final de cada passo: arquivos alterados, comandos, resultado.

## Definicao de pronto por trilha
1. Infra pronta: Postgres ativo, conexao validada e migrations iniciais aplicadas.
2. Backend pronto: endpoints minimos ativos e contrato v1 validado.
3. Front pronto: fluxo de criar/testar/publicar bot funcional sem referencia a Bash.
4. Integracao pronta: ad_hoc_test e run agendada passando.
