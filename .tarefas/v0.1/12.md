# v0.1 - Passo 01: Infra (Docker + PostgreSQL)

## Objetivo
Subir PostgreSQL local em container e preparar base para backend Go.

## Pre-condicoes
1. Docker Desktop instalado e em execucao.
2. Porta 5432 livre.
3. Workspace em d:/dev/ia-go.

## Decisao tecnica
1. Usar imagem oficial postgres no Docker Hub.
2. Persistencia em volume nomeado.
3. Credenciais via arquivo .env local (nao versionado).

## Tarefas
1. Criar arquivo .env.local com:
- POSTGRES_DB=ia_go
- POSTGRES_USER=ia_go_user
- POSTGRES_PASSWORD=<definir>
- POSTGRES_PORT=5432

2. Criar/ajustar docker-compose para servico postgres:
- image: postgres:16-alpine
- healthcheck com pg_isready
- volume persistente
- porta 5432:5432

3. Subir container e validar saude.

4. Criar migration inicial com tabelas:
- bots
- bot_versions
- bot_runs
- run_events

5. Testar conexao com psql ou cliente SQL.

## Criterios de aceite
1. Container postgres em status healthy.
2. Conexao ao banco funcionando.
3. Tabelas iniciais criadas.
4. Credenciais fora do git.

## Comandos de referencia
1. docker compose up -d postgres
2. docker compose ps
3. docker logs <container>
4. docker exec -it <container> psql -U ia_go_user -d ia_go

## Riscos comuns
1. Porta ocupada.
2. Volume antigo com schema inconsistente.
3. Falha de permissao em bind mount.
