# v0.1 - Plano de execucao por sprint

## Sprint 1 - Base tecnica
Entregaveis:
1. Estrutura do backend Go e migrations iniciais.
2. Tabelas de bots, bot_versions, bot_runs.
3. Contrato v1 implementado no backend.

Checklist:
1. CRUD basico de bot funcionando.
2. Validacao de contrato em save.
3. Logs estruturados no backend.

## Sprint 2 - Authoring + teste imediato
Entregaveis:
1. Integracao IA para geracao via template.
2. Fluxo ad_hoc_test ponta a ponta.
3. Exibicao de output padronizado no frontend.

Checklist:
1. Perguntas pendentes quando faltar contexto.
2. ad_hoc_test sem retry automatico.
3. Artifacts de erro disponiveis.

## Sprint 3 - Publicacao + runtime
Entregaveis:
1. Estados de ciclo de vida ativos.
2. Scheduler + dispatcher + queue.
3. Worker Python consumindo jobs.

Checklist:
1. Apenas versao published executa agendado.
2. run_id unico e idempotente.
3. Persistencia completa de status de run.

## Sprint 4 - Confiabilidade
Entregaveis:
1. Retry/backoff deterministico.
2. Heartbeat e deteccao de travamento.
3. Dashboard operacional basico.

Checklist:
1. Falha transitoria reprocessa corretamente.
2. Falha fatal encerra sem retry.
3. Alertas minimos operacionais configurados.

## Fechamento da v0.1
1. Demo fim-a-fim gravada.
2. Runbook de operacao validado.
3. Go-live controlado com 1-2 robos piloto.
4. Plano de v1.0 baseado nos aprendizados.
