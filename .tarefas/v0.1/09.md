# v0.1 - Tickets prontos (formato de issue)

## Como usar
1. Copiar cada ticket para sua ferramenta (GitHub Issues, Jira ou Azure Boards).
2. Manter o ID do ticket para rastreabilidade com os documentos da v0.1.
3. Executar na ordem sugerida para reduzir retrabalho.

## TKT-001 - A1 Tela de criacao por linguagem natural

**Descricao**
Implementar a tela inicial de criacao de automacao onde o usuario descreve em linguagem natural o objetivo do robo.

**Criterios de aceite**
1. Usuario consegue inserir descricao, nome e ambiente alvo.
2. Tela valida campos obrigatorios antes de enviar.
3. Dados sao persistidos como draft.
4. Erros de validacao aparecem de forma clara.

**Dependencias**
1. Banco com tabela de bots e bot_versions.
2. Endpoint de salvar draft.

**Estimativa**
1. 3 pontos.

## TKT-002 - A2 Integracao com template de geracao

**Descricao**
Integrar o backend Go com o template de geracao de bot para chamar o modelo e receber codigo Python estruturado.

**Criterios de aceite**
1. Backend usa .github/prompts/bot-generation-template.md.
2. Placeholder do YAML e preenchido com dados da tela.
3. Resposta do modelo e persistida em bot_versions draft.
4. Falhas de chamada ao modelo retornam erro padronizado.

**Dependencias**
1. TKT-001.
2. Provedor de LLM configurado.

**Estimativa**
1. 5 pontos.

## TKT-003 - A3 Perguntas pendentes obrigatorias

**Descricao**

3. Codigo nao e gerado ate completar respostas.

**Dependencias**
1. TKT-002.

**Estimativa**
